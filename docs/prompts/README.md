# Prompts and planning artifacts

ETHGlobal Tokyo 2026 asks teams using spec-driven workflows to include all spec files, prompts and planning
artifacts. This folder holds them.

| Artifact | What it is |
|---|---|
| `../../PLAN.md` | The plan: narrative, partner picks, architecture, build plan, demo and trust rules. Revised throughout the event. |
| `../INTERFACES.md` | The spec every component was built against (API, contract, profiler, agent, web). |
| `builder-prompts.md` | Verbatim prompts given to AI coding agents that built individual components from the spec. |
| `research-prompts.md` | Verbatim prompts given to AI research agents (ENSv2, MultiBaas, GPU specs). |
| `session-transcript.md` | Full export of the lead Claude Code session (added before submission). |

How it was built: see "How we built it" in the root README.
